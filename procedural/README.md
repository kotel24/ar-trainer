# Процедурная реализация тренажёра

Аналитический этап (КТ2) учебной практики. Программа берёт на себя часть четырёх операций стажировки на вертикально-сверлильном станке 2Н135: показывает шаги операции, проверяет действия стажёра на тренажёре, рассчитывает балл попытки и записывает протокол попытки. Заключение о навыках и отметку о прохождении стажировки по-прежнему делают наставник и мастер участка.

## Язык и зависимости

- Java 21 (проверено на OpenJDK 21.0.10 из JetBrains Runtime, которая входит в IntelliJ IDEA);
- сторонних библиотек нет, используется только стандартная библиотека Java.

Программа написана в процедурном стиле: один класс `Trainer` с методом `main` и статическими методами, данные хранятся в `ArrayList`, `HashMap`, `HashSet` и `PriorityQueue`, собственных классов для сущностей нет.

## Сборка и запуск

Команды выполняются из каталога `procedural` (в архиве КТ2 – из каталога `src`):

```bash
javac -encoding UTF-8 -d out Trainer.java
java -cp out Trainer demo data 1
java -cp out Trainer check data 2
```

| Команда | Что делает | Функции |
|---|---|---|
| `demo <каталог> <сценарий>` | Проверяет сценарий на циклические зависимости и выводит шаги в эталонном порядке (режим «Обучение») | `buildDemoOrder` |
| `check <каталог> <попытка>` | Проверяет действия стажёра, выставляет балл и результат, записывает протокол | `checkActions`, `evaluateAttempt`, `saveAttempt` |

Повторный запуск `check` для той же попытки даёт те же файлы.

## Входные данные

Каталог `data` содержит таблицы логической модели в формате CSV (кодировка UTF-8, разделитель `;`):

| Файл | Сущность |
|---|---|
| `workers.csv` | Работник |
| `scenarios.csv` | Сценарий |
| `steps.csv` | Шаг сценария |
| `dependencies.csv` | Зависимость шагов |
| `internships.csv` | Стажировка |
| `attempts.csv` | Попытка |
| `actions.csv` | Действие попытки |
| `error_kinds.csv` | Вид ошибки |
| `errors.csv` | Ошибка |

Пример: действия попытки 2 из `actions.csv` (номер попытки, порядковый номер, шаг, время от начала в секундах):
