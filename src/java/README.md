# ООП-версия тренажёра 2Н135

Требуется JDK 21. Сторонние библиотеки не нужны. Из каталога с этим README:

```sh
javac -encoding UTF-8 -d out *.java
java -cp out Trainer demo data 1
java -cp out Trainer check data 2
```

Режим обучения выводит 12 шагов с отметками критичных шагов. Режим проверки
обновляет файлы `attempts.csv` и `errors.csv`. Для запуска без изменений в
исходных данных скопируйте каталог `data` и передайте путь к копии.

| Попытка | Балл | Результат |
|---|---:|---|
| 1 | 0 | остановлена |
| 2 | 75 | не сдано |
| 3 | 100 | сдано |

Попытка 2 содержит нарушение порядка при установке сверла и пропуск остановки
шпинделя. Для сравнения можно запустить обе версии с одинаковыми исходными CSV
в разных временных каталогах и сверить вывод и содержимое протокола.
