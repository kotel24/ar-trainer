# ВВЕДЕНИЕ

Работник машиностроительного предприятия не может сразу встать к металлорежущему станку. Сначала он проходит инструктажи, обучение требованиям охраны труда и проверку знаний, а затем стажировку на рабочем месте [1]. Такой порядок связан с тем, что станок опасен: у него есть вращающиеся части, режущий инструмент и стружка. Поэтому Правила по охране труда при обработке металлов прямо запрещают некоторые действия, например работать в перчатках и удерживать обрабатываемую деталь руками [2].

Теорию по охране труда работник сегодня всё чаще изучает в электронном виде, а безопасные приёмы работы отрабатывает на симуляторах и виртуальных тренажёрах [13]. Технологии дополненной (AR, Augmented Reality) и виртуальной (VR, Virtual Reality) реальности уже используются в машиностроении, причём не только для обучения персонала, но и для сопровождения производственных операций [9]. Тренажёр, на котором работник отрабатывает порядок действий до выхода к станку, а результат оценивается объективно, позволяет снизить риск на стажировке. Поэтому его разработка является актуальной задачей.

Тема практики – «Разработка тренажёров дополненной реальности для промышленных предприятий».

Объект исследования – процесс практической подготовки рабочего персонала машиностроительного предприятия к безопасной работе на металлообрабатывающем оборудовании.

Предмет исследования – программное средство отработки и проверки выполнения операции на оборудовании по сценарию, рассмотренное на примере стажировки на вертикально-сверлильном станке 2Н135.

Цель работы – разработать программное ядро тренажёра, то есть программу, которая хранит сценарий операции как данные, проверяет порядок действий обучаемого, фиксирует ошибки и формирует результат прохождения. Ядро не зависит от способа отображения, поэтому позднее к нему можно подключить интерфейс дополненной реальности, не меняя логику проверки.

Для достижения цели поставлены задачи, по одной на каждый этап практики:

1) исследовательский этап: проанализировать предметную область, описать бизнес-процесс стажировки на станке, выбрать и освоить среду разработки и систему контроля версий, перевести фрагмент иностранного источника по теме, сформировать список источников;
2) аналитический этап: построить модель бизнес-процесса в нотации BPMN 2.0 (Business Process Model and Notation) [6; 18], выявить автоматизируемые операции, разработать логическую модель данных, а также алгоритмы проверки сценария и реализовать их на языке Java в процедурном стиле;
3) организационный и объектно-ориентированный этап: спроектировать классы ядра тренажёра, реализовать ту же задачу на языке Java в объектно-ориентированном стиле и сопоставить обе реализации;
4) проектный этап: реализовать физическую модель данных в системе управления базами данных (СУБД) PostgreSQL, составить тестовые сценарии, проверить качество кода и описать проектное решение.
