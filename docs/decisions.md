# Принятые решения

Зафиксировано 22.09.2026, пересмотрено 28.09.2026 по памятке КТ1 и письму руководителя.

## Предмет

1. Основной бизнес-процесс — стажировка работника на рабочем месте перед допуском к самостоятельной работе на станке 2Н135. Процесс начинается с распоряжения мастера о стажировке и заканчивается допуском или продлением стажировки.
2. Отрасль — машиностроение.
3. Сквозной пример — вертикально-сверлильный станок 2Н135, сценарий «Подготовка станка и сверление отверстия».
4. Тренажёр не заменяет стажировку. Стажёр проходит сценарий до выхода к станку, наставник получает протокол ошибок.

## Объём реализации

5. Только обязательная часть задания: Python (процедурно), Java (ООП), СУБД. AR-прототип на Unity не делаем; возможен позже как надстройка.
6. Сценарии хранятся как данные; движок универсальный. Для тестов — второй игрушечный сценарий на 3–4 шага.
7. Режимы: «Обучение» и «Проверка». Ядро проверки не зависит от графики.
