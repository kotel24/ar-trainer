# СРЕДА РАЗРАБОТКИ И СИСТЕМА КОНТРОЛЯ ВЕРСИЙ

## Среда разработки

Выбрана среда IntelliJ IDEA компании JetBrains. Начиная с версии 2025.3 она распространяется единым дистрибутивом, и её базовые возможности бесплатны. В одной среде можно вести обе части проекта: Java поддерживается изначально, Python подключается плагином. В среду встроены клиент Git, отладчик и средства рефакторинга, которые понадобятся на объектно-ориентированном этапе. Рассматривались также Visual Studio Code и PyCharm. У первого средства рефакторинга Java заметно беднее, второй не поддерживает Java.

## Языки программирования

Процедурная реализация алгоритмов выполняется на языке Python версии 3.12. Язык позволяет коротко записывать алгоритмы обхода и проверки сценария, а его стандартная библиотека содержит нужные структуры данных: списки, словари, множества и очереди [4; 14]. Версия 3.12 выбрана как стабильная и поддерживаемая плагином Python для IntelliJ IDEA.

Объектно-ориентированная реализация выполняется на языке Java 21, дистрибутив Eclipse Temurin. Java 21 — версия с долгосрочной поддержкой. В ней есть записи (records), запечатанные интерфейсы и сопоставление с образцом в операторе switch [15]. Эти средства удобны для описания шагов сценария, типов ошибок и результатов проверки.

## Система управления базами данных

Для хранения сценариев и результатов прохождения выбрана СУБД PostgreSQL 18. Это свободная реляционная СУБД. Данные тренажёра хорошо ложатся на реляционную модель: сценарий состоит из шагов, шаги связаны зависимостями, а попытки прохождения ссылаются на сценарий и содержат ошибки. PostgreSQL поддерживает ограничения целостности, транзакции и тип JSONB, в котором можно хранить описание сценария целиком [10]. К ней подключаются и Python, и Java, поэтому обе реализации будут работать с одной базой.

## Система контроля версий

Выбрана распределённая система контроля версий Git версии 2.50.1. В распределённой системе каждая рабочая копия содержит полную историю, поэтому коммиты и просмотр истории выполняются без подключения к серверу. Git встроен в IntelliJ IDEA и уже установлен на рабочей станции. Удалённый репозиторий размещён на GitHub: сервис бесплатен для открытых репозиториев и даёт руководителю доступ к проекту по ссылке. Полная копия репозитория хранится и локально, поэтому при необходимости её можно перенести на другой сервис.

Репозиторий ar-trainer содержит файл README.md с темой практики и ФИО обучающегося, файл .gitignore, который исключает служебные файлы среды и результаты сборки, а также каталоги docs (разделы отчёта и список источников), python, java и db. Сообщения коммитов пишутся на русском языке и описывают изменение, например «Добавлен список источников». Сдача каждой контрольной точки отмечается тегом kt1–kt4.
