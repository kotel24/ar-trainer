# СРЕДА РАЗРАБОТКИ И СИСТЕМА КОНТРОЛЯ ВЕРСИЙ

## Среда разработки

Выбрана среда IntelliJ IDEA компании JetBrains. С версии 2025.3 она распространяется единым дистрибутивом, базовые возможности которого бесплатны. В одной среде можно вести обе части проекта: Java поддерживается изначально, Python подключается плагином. В среду встроены клиент Git, отладчик и средства рефакторинга. Рассматривались также Visual Studio Code и PyCharm, но у первой средства работы с Java заметно беднее, а вторая не поддерживает Java.

## Языки программирования

Процедурная реализация алгоритмов выполняется на языке Python 3.12. Язык позволяет коротко записывать алгоритмы обхода и проверки сценария, а его стандартная библиотека содержит нужные структуры данных: списки, словари, множества и очереди [4; 14]. Версия 3.12 выбрана как стабильная и поддерживаемая плагином Python для IntelliJ IDEA.

Объектно-ориентированная реализация выполняется на языке Java 21 в дистрибутиве Eclipse Temurin. Java 21 — версия с долгосрочной поддержкой, в ней есть записи (records), запечатанные интерфейсы и сопоставление с образцом в операторе switch [15]. Эти средства удобны для описания шагов сценария, видов ошибок и результатов проверки.

Работа среды проверена программами python/hello.py и java/src/Hello.java из репозитория проекта, которые выводят версию языка.

## Система управления базами данных

Для хранения сценариев и результатов прохождения выбрана свободная реляционная СУБД PostgreSQL 18. Данные тренажёра хорошо ложатся на реляционную модель: сценарий состоит из шагов, шаги связаны зависимостями, а попытки прохождения ссылаются на сценарий и содержат ошибки. PostgreSQL поддерживает ограничения целостности, транзакции и тип JSONB для хранения описания сценария целиком [10]. К ней подключаются и Python, и Java, поэтому обе реализации будут работать с одной базой.

## Система контроля версий

Выбрана распределённая система контроля версий Git 2.50.1: каждая рабочая копия содержит полную историю, а сама система встроена в IntelliJ IDEA. Удалённый репозиторий ar-trainer размещён на GitHub, что даёт руководителю доступ к проекту по ссылке.

Репозиторий содержит файл README.md с темой практики и ФИО обучающегося, файл .gitignore, исключающий служебные файлы среды и результаты сборки, а также каталоги docs (разделы отчёта), python, java и db. Сообщения коммитов пишутся на русском языке и описывают изменение, например «Добавлен список источников».
