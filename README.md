# Разработка тренажёров дополненной реальности для промышленных предприятий

Учебная практика, РТУ МИРЭА, Институт информационных технологий, кафедра игровой индустрии, 2026.

Обучающийся: Котельников Дмитрий Владимирович, группа ИКБО-31-24.

Ядро тренажёра для отработки и проверки операций на металлообрабатывающем оборудовании. Сценарии хранятся как данные; первый сценарий — подготовка вертикально-сверлильного станка 2Н135 и сверление отверстия. Тренажёр работает в двух режимах: «Обучение» (демонстрация шагов) и «Проверка» (самостоятельное выполнение шагов с контролем порядка и ошибок). Ядро проверки не зависит от графики.

## Структура

| Папка | Содержимое |
|---|---|
| `docs/` | Разделы отчёта по практике, список источников |
| `python/` | Процедурная реализация алгоритмов (Python 3.12) |
| `java/` | Объектно-ориентированная реализация (Java 21) |
| `db/` | Физическая модель данных (PostgreSQL 18) |

## Правила работы с репозиторием

- Сообщения коммитов пишутся на русском языке и описывают, что изменилось, например «Добавлен список источников».
- Сдача контрольной точки отмечается тегом: `kt1`, `kt2`, `kt3`, `kt4`.
